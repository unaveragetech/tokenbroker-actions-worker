# Third-party components

- **BigMoeOnEdge** (`bin/bmoe-cli`, v0.28.0 release build, sha256 in
  `bin/bmoe-cli.sha256`) - Apache-2.0, https://github.com/Helldez/BigMoeOnEdge
  (built on llama.cpp, MIT). Licence text: `bin/BigMoeOnEdge-LICENSE`.
- **Qwen3-30B-A3B** - model by the Qwen team (Alibaba Cloud), Apache-2.0.
  Q3_K_M quantisation by bartowski
  (https://huggingface.co/bartowski/Qwen_Qwen3-30B-A3B-GGUF). The GGUF is
  mirrored, split into <2 GiB parts, as assets of the release
  `model-qwen3-30b-a3b-q3_k_m` so the workflow doesn't depend on Hugging Face.
